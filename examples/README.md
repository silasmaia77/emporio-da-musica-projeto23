# Conversation examples

The five `.md` transcripts are **scripted model simulations**, not real LLM or WhatsApp conversations. They are generated by `python examples/generate_examples.py` using the real Agent, typed tools, supplied database and policy retriever, with an explicitly scripted model client. This makes the integration reproducible without claiming generative behavior was tested live.

For real model validation, use notebook block 22 and manually review grounding, tone, context and scope. Tool traces accompany each simulated transcript. No real customer data is sent externally by the generator.
