EMPÓRIO DA MÚSICA — PROJETO COMPLETO

1. Extraia o ZIP e abra a pasta emporio_da_musica.
2. Instale Python 3.10.
3. Crie e ative o ambiente virtual conforme README.md.
4. Instale: python -m pip install -r requirements-dev.txt
5. Copie .env.example para .env e preencha OPENAI_API_KEY e OPENAI_MODEL.
6. Importe a base: python -m src.data.importer
7. Abra o chat: streamlit run app.py

O seletor de cliente na interface é uma identidade simulada para demonstrar os pedidos.
Não exponha essa interface local como login público de clientes.
